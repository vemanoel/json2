## Development

### Prerequisites

- [Zed](https://zed.dev)
- [Mise](https://mise.jdx.dev)

### Environment setup

1. Go to the project directory
2. Run `mise trust`
3. Run `mise install`

### Daily Commands

```bash
mise tasks ls     # list available tasks
mise r [task]     # run a task
mise r [task] -h  # show task help
```
