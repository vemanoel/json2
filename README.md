## Development

### Prerequisites

- [Zed](https://zed.dev)
- [pkgx](https://github.com/pkgxdev/pkgx#readme)

### Commands

```bash
pkgx just run [args]            # run the application
pkgx just crossbuild            # build for all platforms
pkgx just build [os] [target]   # build for a specific platform
```
