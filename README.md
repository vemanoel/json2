## Development

### Prerequisites

- [Zed](https://zed.dev)
- [Mise](https://mise.jdx.dev)

### Environment setup

1. Go to the project directory
2. Run `mise trust`
3. Run `mise install`
4. Run `mise tasks ls`

### Daily Commands

```bash
mise tasks ls    # List available tasks
mise run [task]  # Run a task
```
